# Tucong 首页学习笔记

参考地址：https://www.tucong.vip/

首页最值得学的是“第一屏之后不突然降级”。它的首屏并不堆复杂组件，而是把站点名称、短句、向下提示和导航先讲清楚；真正的密度从首屏下面开始释放。最新文章区不是普通三列卡片，而是用标题、日期、阅读、评论、点赞和摘要形成内容索引，让用户一眼知道哪些内容值得点。分类区更像一个轻量目录，用“继续探索这个分类下的内容”和数字建立下一步行动，而不是只摆几个标签。

我在当前站点中对应做了三件事：第一，首屏增加滚轮吸附，向下直接进入内容区，上划回首屏；第二，最近文章优先展示有封面的旧文，没有封面时使用 logo 兜底；第三，把首页入口重新收束为在看、在玩、留言、友人帐、诗集、项目，避免导航和首页重复拥挤。

可继续深化的方向：底部可以再做“关于我”和“推荐入口”的信息带，承接 Tucong 首页后半段那种温和但很完整的收束感；分类区可以在后续用真实分类色块做出更强的可视层级。
