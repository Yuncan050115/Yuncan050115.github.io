# Tucong 文章页 Pinkbin 学习笔记

参考地址：https://www.tucong.vip/archives/pinkbin

文章页的关键不是“正文居中”这么简单，而是阅读辅助系统。Tucong 文章页具备清晰标题区、正文、目录、阅读数据、评论入口和页尾信息，用户知道自己在哪、读到哪、读完以后能做什么。阅读进度和目录尤其重要：进度给全局反馈，目录给局部定位。

旧站 Butterfly 也有类似细节：文章末尾会显示作者、发布于、更新于、许可协议，许可协议是 CC BY-NC-SA 4.0。这种彩色信息框看似小，但它让文章从“网页内容”变成“有归属、有时间、有边界的作品”。

本次新站文章页已加入顶部阅读进度条、右侧目录、正文图片兜底、文章版权彩色框和 Twikoo 评论锚点。右键菜单中的“空降评论”和“复制本文地址”也已经接上对应动作。
