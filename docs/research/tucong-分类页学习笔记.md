# Tucong 分类页学习笔记

参考地址：https://www.tucong.vip/categories

分类页和标签页共用同一套头部语言，但内容呈现更强调结构。分类不是关键词散点，而是站点内容的骨架，所以它需要卡片、数量和“探索”动作。Tucong 的分类区没有用很重的图片背景，核心是文字、数字、行动按钮之间的节奏。

当前新站分类页使用旧文章 frontmatter 生成，后续应继续补两点：其一，分类卡片可显示最近一篇文章标题，让分类从“静态文件夹”变成“正在生长的入口”；其二，分类颜色要克制，不要每个分类都抢主视觉，避免破坏全站统一动效。

本次导航调整已把分类归入“文章”。这是符合分类页信息架构的：分类、标签、归档都属于文章的三种索引方式，不应该和留言板、在看、个人入口抢同一级。
