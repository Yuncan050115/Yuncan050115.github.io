# Tucong 归档页学习笔记

参考地址：https://www.tucong.vip/archives

归档页重点是时间线和扫读效率。Tucong 的归档不是简单罗列标题，而是把年份、序号、日期和标题压进统一节奏里，读者滚动时能自然感到内容在时间上推进。它的导航在滚动后也会变得更轻，靠向页面右侧，让主体列表拥有更多呼吸空间。

新站本次已经实现下滑后导航向右靠拢，并保留透明毛玻璃质感。归档页现有文章卡片仍偏卡片流，下一步可以进一步收紧为“年份分组 + 横向细线 + 小封面/标题”的形态，让归档页比首页更适合快速定位。

归档页还应该和阅读进度体系联动：当用户进入文章页后，顶部阅读进度条、右侧目录、文章底部版权框要构成完整闭环。本次文章页已经补上这些结构。
