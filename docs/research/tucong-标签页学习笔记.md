# Tucong 标签页学习笔记

参考地址：https://www.tucong.vip/tags

标签页没有把标签做成传统列表，而是强调关键词云。页面先给出标题、说明，再用 Keywords 和 Shape 两个小指标建立“这是标签集合”的认知，最后进入标签云。每个标签带文章数量，数量不是附属信息，而是标签权重的一部分。

新站当前标签页已经能从旧 Markdown 的 frontmatter 生成真实标签。下一步应把标签云做得更有呼吸感：不同文章数对应不同字号和透明度，hover 时轻微上浮并改变描边颜色。这里不应加太重的卡片，因为标签本身就是快速跳转工具，过度装饰会拖慢扫描效率。

导航层面，Tucong 把标签归入“文章”分组，而不是放在顶层。我已经按这个逻辑把归档、标签、分类收进“文章”弹性导航里，避免顶栏横向爆炸。
