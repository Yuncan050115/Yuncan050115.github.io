# 云灿个人主页

一个基于Astro+Vue的优雅个人主页。感谢imsyy的原项目
[https://github.com/imsyy/home]。

## 🆕 最新更新 (2025年4月22日)

- **字体优化** - 使用景华老宋字体(JinghuaLaosong)作为全站默认字体
- **节日系统** - 大幅扩展节日系统，支持上百个节日和角色生日，添加特效
- **移动端优化** - 修复汉堡按钮，调整网站列表布局，解决显示问题
- **性能优化** - 精简控制台输出，提高页面加载速度

## 🚀 技术栈

- **Astro** - 高性能静态站点构建框架
- **Vue 3** - 渐进式JavaScript框架（使用Composition API）
- **Element Plus** - Vue 3的组件库
- **Pinia** - Vue的状态管理库
- **SCSS** - CSS预处理器
- **PWA** - 渐进式Web应用支持

## ✨ 特点

- 🚀 **高性能** - 使用Astro提供最优的静态站点性能
- 📱 **响应式** - 适配各种设备屏幕尺寸
- 🔄 **状态管理** - 使用Pinia管理状态并支持持久化
- 🎨 **美观优雅** - 精心设计的UI界面
- 🔒 **PWA支持** - 支持离线访问和应用安装
- 🌙 **壁纸切换** - 支持显示精美壁纸
- 🎂 **节日系统** - 丰富的节日提醒和特效

## 🛠️ 开发

```bash
# 安装依赖
npm install

# 开发服务器
npm run dev

# 构建
npm run build

# 预览构建结果
npm run preview
```

## 🌐 环境变量

在`.env`文件中配置站点信息、API密钥等。
