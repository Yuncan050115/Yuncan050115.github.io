# 多项 UI Bug 修复与功能增强 Spec

## Why
用户反馈多个严重问题：音乐播放器被错误修改导致右侧空白更大、Three.js 动效卡顿且白天几乎不可见、Steam 游戏页面卡顿且不显示正确账号数据、右键菜单不工作、诗集页面需要重新设计、文章赞赏功能无法显示。

## What Changes
- 回退音乐播放器样式到上一版本，修复右侧空白问题，添加主题适配（日间白色背景、夜间灰黑色背景）
- 重写 Three.js 动效，优化性能减少卡顿，重新设计白天模式的明显动效
- 优化 Steam 游戏页面加载性能，确保使用正确 Steam ID 获取数据
- 修复右键菜单初始化逻辑，确保在页面切换后正常工作
- **不修改**主页分类 UI 代码，仅研究其实现原理并记录
- 重做诗集页面：按目录视图（古生古色风格）和按时间轴视图两种模式，置顶白云山诗篇，添加防复制保护
- 修复文章赞赏弹窗显示 bug

## Impact
- Affected code: `src/styles/site.css`, `src/scripts/app.ts`, `src/layouts/BaseLayout.astro`, `src/pages/steamgames.astro`, `src/pages/poems.astro`, `src/pages/posts/[slug].astro`, `src/lib/content.ts`

## ADDED Requirements

### Requirement: 音乐播放器主题适配
系统 SHALL 提供音乐播放器的主题适配功能：
- 日间模式：白色/浅色背景，深色文字
- 夜间模式：灰黑色背景，白色文字
- 分时段自动切换：6:00-18:59 使用日间模式，其余时间使用夜间模式
- 修复右侧空白：歌单区域仅在悬停时展开，默认状态紧凑显示

#### Scenario: 日间模式显示
- **WHEN** 系统处于日间模式（light）
- **THEN** 音乐播放器背景为白色/浅色半透明，文字为深色

#### Scenario: 夜间模式显示
- **WHEN** 系统处于夜间模式（dark）
- **THEN** 音乐播放器背景为灰黑色半透明，文字为白色

### Requirement: Three.js 动效优化
系统 SHALL 提供流畅的 Three.js 背景动效：
- 白天模式：明显的金色/橙色光晕和粒子效果，肉眼可见
- 夜间模式：星空和蓝紫色粒子效果
- 光标互动：粒子跟随光标产生排斥/吸引效果，响应流畅不卡顿
- 性能优化：减少粒子数量，优化渲染循环，使用 requestAnimationFrame 正确调度

#### Scenario: 白天动效可见
- **WHEN** 用户处于日间模式浏览页面
- **THEN** 背景有明显的金色光晕和暖色粒子漂浮效果

#### Scenario: 光标互动流畅
- **WHEN** 用户移动光标
- **THEN** 粒子在光标附近产生排斥效果，响应延迟小于 50ms

### Requirement: Steam 游戏正确加载
系统 SHALL 使用正确的 Steam ID 加载游戏数据：
- 使用配置中的 `steamId: '76561199167590911'`
- 优化加载性能：减少 API 请求超时，添加加载状态提示
- 失败时显示友好错误提示

#### Scenario: 正确账号数据
- **WHEN** 用户访问 Steam 游戏页面
- **THEN** 显示 `76561199167590911` 账号的游戏列表

### Requirement: 右键菜单正常工作
系统 SHALL 提供自定义右键菜单功能：
- 阻止默认右键菜单
- 显示自定义菜单选项：后退、前进、刷新、回顶、复制地址、去评论、昼夜切换、打印
- 页面切换后菜单仍然正常工作

#### Scenario: 右键菜单显示
- **WHEN** 用户右键点击页面
- **THEN** 显示自定义右键菜单而非浏览器默认菜单

### Requirement: 诗集页面双视图
系统 SHALL 提供诗集页面的两种浏览模式：
- 按目录视图：古生古色风格，按辑分组显示，置顶白云山诗篇
- 按时间轴视图：按时间顺序显示，置顶白云山诗篇
- 防复制保护：禁止右键复制、禁止 Ctrl+C、禁止 F12 开发者工具

#### Scenario: 目录视图显示
- **WHEN** 用户选择按目录浏览
- **THEN** 诗篇按辑分组，使用古生古色风格（古典边框、书法字体风格）

#### Scenario: 防复制保护
- **WHEN** 用户尝试复制诗集内容
- **THEN** 系统阻止复制操作并显示提示

### Requirement: 文章赞赏显示
系统 SHALL 正确显示文章赞赏弹窗：
- 点击"赞赏作者"按钮后弹窗正常显示
- 显示支付宝和微信收款码图片

#### Scenario: 赞赏弹窗显示
- **WHEN** 用户点击赞赏按钮
- **THEN** 弹窗显示收款码图片和感谢文字

## MODIFIED Requirements

### Requirement: 主页分类 UI 研究
系统 SHALL 保留主页分类 UI 的现有实现（不做修改），并记录其设计原理：
- Flex 布局实现悬停展开效果
- `flex: 1` 默认等分，悬停时 `flex: 2` 展开
- 使用 `cubic-bezier(.16, 1, .3, 1)` 缓动函数实现流畅过渡
- 此设计思路可扩展到其他页面（如归档页）
